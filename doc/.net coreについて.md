## Nugetの管理

- CLI

 - 導入  
   dotnet add package <PACKAGE_NAME> -v

 - 削除  
   dotnet remove package <PACKAGE_NAME>

 - 一覧  
   dotnet list package

- GUI

拡張機能の NuGet Package Manager GUI をインストールする

Nugetのインストール後、.csprojのPackageReferenceに追加される。

GUIベースでの確認の方が便利
