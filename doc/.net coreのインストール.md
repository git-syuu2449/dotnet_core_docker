# .Net Core


## dotnet

```bash
sudo apt update
sudo apt install -y dotnet-sdk-8.0

# バージョン確認
dotnet --list-sdks
```

dotnetは共存できるので、バージョンの切り替えは可能。

### バージョン管理方法

`global.json`にて管理をする。  
グローバル環境（global.json 無し）では最新版が使われる。

```bash
# 作成コマンド
dotnet new globaljson --sdk-version バージョン

# global.jsonが作成される
```

## SSMS

以下の構成

ホスト(Windows)→　←virtualbox(仮想環境のホスト)→　←db(コンテナ)

ホストのWindowsからSSMSにてコンテナのdbに接続を行う。

変更点

- Virtualbox

設定→ネットワーク→割当（NAT）、ポートフォワーディング(ホストポート、ゲストポートをSQLServerに合わせる)

- SSMS

 - Server Name: localhost  ポートの変更をしている場合(1433以外)は localhost,1111　のように設定
 - Auth: SQL Server認証
 - User Name: sa
 - Password: 設定したパスワード
 - Advanced
   - Trust Server: True

- VSCode

　拡張機能のSQL Serverを入れている場合  
　SSMSと同様の為省略
